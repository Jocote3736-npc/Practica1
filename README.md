# Practica 1
## Sistema de Gestión de Tickets

## Archivos del Proyecto

- **`Ticket.java`**: Modelo de datos del ticket con identificador único autoincrementable.
- **`ColaDinamica.java`**: Cola de prioridad para gestionar los tickets pendientes en orden de atención.
- **`ListaEnlazadaTicket.java`**: Lista enlazada simple para almacenar los tickets resueltos.
- **`Main.java`**: Interfaz de consola con menús de usuario y administrador.
